# MBTI Reigns: 人格之骰 👑

基于《王权》（Reigns）核心滑动玩法打造的沉浸式 MBTI 人格决策卡牌游戏。

- 🎮 **王权经典机制**：拖拽/滑动卡片做出抉择，实时影响四大神柱派系平衡。
- ⚖️ **四大命定神柱**：心神之火 (E/I)、全知之眼 (S/N)、审判天平 (T/F)、秩序沙漏 (J/P)。
- 🔮 **中世纪宫廷美学**：金箔边框、羊皮纸暗调、裁决火漆印章与古典衬线字体。
- 🎵 **合成复古音效**：Web Audio API 纯原生算法合成决策声与加冕乐。
- 📜 **命定加冕诏书**：15 轮裁决后生成专属于你的 MBTI 人格诏书与封印徽章。
